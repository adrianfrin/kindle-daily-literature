# 每日文学哲学推荐

文学与哲学文章的完整 Markdown 归档。

## 文件约定

- `articles/文章完整标题.md`：完整 UTF-8 正文，保留标题、自然段、必要小标题与原有参考链接。
- `manifest.json`：最近最多 60 条文章记录，按日期倒序，同一天仅一条。每条记录包含日期、完整标题、Markdown 路径与对应文件的 Git blob SHA。
- `cloud-publishing-instructions.txt`：云端任务的文章发布要求。

文件名保留中文与常用标点，将路径敏感字符替换为对应全角字符。移除控制字符和文件名末尾的空格、句点；检测大小写与 Unicode 规范化后的路径冲突。正文标题保持原样。

## 发布顺序

先写入完整文章，确认对应文件的最新 blob SHA，再更新 manifest。目录更新前读取最新 SHA，防止覆盖并发更新。同日换标题时，先完成新文章和目录更新，再核对最新 SHA 并删除被替换的旧文章。

只发布文章正文和参考链接，不发布聊天历史、账户资料、设备信息或凭证。

- [方法变更日志](agents/weekly-literature-changelog.md)：只记录实质策略修订，不每周重写规范。
- [推荐历史](weekly-literature/history.jsonl)：长期三书与切入问题记录，供跨 Agent 去重；不受 manifest 最近 60 条限制。
- [周刊索引](weekly-literature/manifest.json)：沿用 v1 的日期、标题、路径与文章 blob SHA；仅登记已核实的正文。初始化为空，不代表旧稿已归档。

使用顺序：先读周刊规范与通用手册的接入说明，再读通用方法、完整推荐历史和近期文章。通用手册解释怎么写，周刊规范规定本任务怎么执行。旧稿的字数、主题轮换和单主作品建议不覆盖当前持续存在主义主线、固定三书与不设默认字数的要求。
